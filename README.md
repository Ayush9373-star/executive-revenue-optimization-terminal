## Project Genesis: Data Engineering Execution.

### Python Data Pipeline: What I Did, How, and Why?
I built a data tool in Python that loads the massive 3.4 Million row file in smaller, safe batches. Normal tools and charts freeze or crash when loading huge files into computer memory all at once. My tool uses automatic cleaning rules to catch data errors: it turns empty timeline boxes into clear tracking numbers to prevent system errors, keeping the database perfectly safe.

### SQL Database Setup: What I Did, How, and Why?
I built the main data tables inside a MySQL database using simple data filters and table linking commands. Raw records give no value to business leaders. I optimized the database with custom indexing tags to search data very fast: this brought wait times down to under 5 seconds, letting me isolate key user habits easily.

### Dashboard Visual Design: What I Did, How, and Why?
I linked the database to Power BI, cut out heavy useless columns to lower memory load by 70 percent, built safe math metrics, and designed a custom dark mode screen. Traditional bright white charts tire the eyes and hide answers across multiple confusing pages. This black canvas focuses your attention instantly on critical metrics.

## Core Business Insights and Strategic Answers: What Are We Solving?

### Insight 1: New User Drop Offs.

The Customer Drop Off Problem:
The business problem centers on finding the exact milestone drop offs where new users stop buying things during their onboarding journey.

The Drop Off Fix:
The answer is that the system finds a big 46 percent customer drop happening between order 2 and order 10: however, the data proves that users who make it past order 4 get completely hooked. Their purchase wait time at home drops from 15.3 days down to 12.4 days: this shows management that discount budgets should be stopped for loyal users past order 4, and moved to rescue accounts shifting between orders 2 and 3.

### Insight 2: Users Leaving the App.

The Vanishing Customer Problem:
The business problem focuses on tracking how many core, active weekly shoppers have broken their habits and stopped opening the app.

The Vanishing Customer Fix:
The answer is that the system successfully flags exactly 27,211 premium users who completely stopped using the app: they disappear for a long average gap of 26.5 days. This signals a big competitor threat: it gives product managers the exact numbers needed to fire automated app discount vouchers on Day 21 to pull them back.

### Insight 3: Busiest Shopping Hours.

The Website Rush Hour Problem:
The business problem demands identifying our absolute busiest checkout hours of the day to prevent server lag and high computer bills.

The Website Rush Hour Fix:
The answer is that the data grid exposes an extreme daytime rush hour concentration: the top 5 peak hours of 10:00 AM, 11:00 AM, 1:00 PM, 2:00 PM, and 3:00 PM compress a huge 41.4 percent of all weekly transactions into a narrow 5 hour window. This provides the exact operational numbers needed to run server auto scaling rules: this workflow completely eliminates server cost waste.

### Insight 4: Best Customer Groups.

The Value Spender Problem:
The business problem involves separating highly valuable, regular power spenders from low margin casual shoppers to protect the core user line.

The Value Spender Fix:
The analysis shows a sharp concentration: while 175,532 casual shoppers drop out early after a brief average journey of 10.8 orders, an elite core asset of 30,677 VIP Power Spenders displays massive loyalty. They average an intense 49.5 lifetime orders per user: this group represents the financial anchor of the marketplace.

### Insight 5: Best Selling Products.

The Item Stockout Problem:
The business problem requires identifying the exact popular grocery items that our top 30,000 VIP power spenders buy the most to avoid empty shelves.

The Item Stockout Fix:
The data shows a heavy purchase dependency on items like Potatoes O'Brien and White Albacore Tuna: this shows warehouse managers exactly where to focus extra stocks to protect core shopping loops.
